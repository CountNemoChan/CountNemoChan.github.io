# Li-Heng Chen Portfolio

Personal academic website for Li-Heng Chen, built with React and React Bootstrap.

The site includes:

- Home page with current research identity and contact links
- About page with education, research focus, skills, tools, and GitHub activity
- Selected academic work with publication teasers and paper links
- Resume page with downloadable CV

## Development

Install dependencies:

```bash
npm install
```

Run locally:

```bash
npm start
```

Build for production:

```bash
npm run build
```
